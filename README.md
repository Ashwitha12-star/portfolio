# Ashwitha Racharla Portfolio

A responsive personal portfolio built with React + Vite.

## Included
- About section
- Technical skills
- Featured projects
- Education and training
- Certifications with the supplied certificate URLs
- Achievements
- GitHub, LinkedIn and LeetCode links
- Email and phone contact
- Dark/light theme
- Mobile navigation

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Deploy

This project is ready for GitHub Pages or another static host. For a Vite project hosted at a repository URL such as `https://USERNAME.github.io/REPO/`, set the Vite `base` to `'/REPO/'` before deploying. See the official Vite deployment guide:
https://vite.dev/guide/static-deploy

## Important
The project cards currently point to your GitHub profile because project-specific repository URLs were not provided. Replace those links in `src/main.jsx` when you have the individual project repositories.
